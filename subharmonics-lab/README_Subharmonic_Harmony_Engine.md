# Subharmonic Harmony Engine

## Research Notes and Vision (July 2026)

## Vision

The long-term goal is not to build another synthesizer.

The goal is to develop a Subharmonic Harmony Engine that augments
existing music with a physically meaningful low-frequency layer
combining: - subharmonic support - harmonic relationships -
rhythm-locked beat structures - pleasant body resonance

Sleep Elsi is one application of this engine, but the engine itself is
intended to become an independent technology.

## Current Research

Current laboratory: - Subharmonic Harmony Lab

Purpose: - explore harmonic ratios - evaluate body perception - study
rhythmic beat generation - develop reusable DSP building blocks before
Sleep Elsi integration

## Fundamental Principles

### Beat first

The rhythmic layer is more important than perfect harmonic analysis.

### Harmony second

Harmony improves the result whenever it can be estimated with sufficient
confidence.

### Body resonance

The generated layer should feel supportive rather than dominant.

## Beat Pair Concept

Only the harmonic pair responsible for the desired beat is emphasized: -
m × Base - n × Sub

This maximizes beat clarity while minimizing unwanted interference.

## Future Harmony Sets

## Rhythm Philosophy

The engine should exhibit rhythmic attraction rather than perfect tempo
lock.

Behavioural states: - Locked - Loose - Syncopated - Suspended - Return

Occasional perfect alignment is desirable.

## Human Interaction

The user provides rhythmic intent by tapping.

Tap rhythm → Estimated pulse → Beat target → Automatic harmony selection

The user supplies intention. The engine performs optimisation.

## Future Architecture

Music Input → Rhythm Detector → Harmony Detector → Decision Layer →
Subharmonic Harmony Engine → Playback

## Immediate Next Milestone

Playback Lab

Features: - Load music - Play/Pause - Virtual keyboard - Manual base
note - Existing Subharmonic Engine - Beat Pair - Timeline - Record
performed bass line

No automatic analysis yet.

Goal: Discover which bass notes and harmonic structures naturally
enhance real music.

## Long-term Goal

A new musical instrument.

The musician provides rhythm.

The engine creates a coherent subharmonic resonance field beneath the
music.
